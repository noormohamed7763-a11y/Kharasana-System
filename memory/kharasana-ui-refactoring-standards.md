تجنب استخدام `ViewBag` لنقل البيانات التي تستخدم في العرض أو المنطق البرمجي داخل الـ Views. يجب إضافتها إلى الـ `ViewModels` لضمان سلامة النوع (Type safety) وسهولة الصيانة.
كذلك، يجب نقل منطق JavaScript من ملفات الـ Views إلى ملفات خارجية (تحت `wwwroot/js`) لضمان الفصل التام بين منطق العرض ومنطق التفاعل، ولتسهيل الاختبار والصيانة.

**لماذا:**
- تحسين قراءة الكود.
- تقليل أخطاء وقت التشغيل (Runtime errors).
- تعزيز قابلية الاختبار وإعادة الاستخدام.

**كيفية التطبيق:**
1. تحديث الـ ViewModel المقابل للصفحة.
2. تحديث الـ Controller لتعبئة بيانات الـ ViewModel الجديدة.
3. تحديث الـ View لاستخدام خصائص الـ Model بدلًا من `ViewBag`.
4. نقل منطق JS إلى ملف `.js` منفصل وربطه بـ View.
